# Aurora Board — 無限フリーボード（GitHub Pages + Firebase 無料枠）

サーバーを自分で立てずに動かす、リアルタイム共同編集の無限ホワイトボードです。
フロントは GitHub Pages、データ保存・同期は Firebase Realtime Database（Spark 無料プラン）を使います。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで全機能） |
| `firebase-config.js` | Firebase の接続情報（あなたが貼り付ける） |
| `sw.js` | 通知表示用 Service Worker |
| `database.rules.json` | Firebase に設定するセキュリティルール |

`firebase-config.js` を空のままでも「ローカルモード」で動きます（この端末のブラウザ内のみ保存・共有なし）。動作確認に使えます。

## セットアップ（所要 約10分・クレジットカード不要）

### 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com で「プロジェクトを追加」（Analytics は不要）
2. 左メニュー **構築 → Realtime Database → データベースを作成**（場所は `asia-southeast1` など近い所、モードは「ロックモード」）

### 2. ルールを貼る
Realtime Database の **ルール** タブに `database.rules.json` の内容を貼って「公開」。

### 3. 匿名認証をオンにする
**構築 → Authentication →始める → Sign-in method → 匿名 → 有効化**
（ルールが `auth != null` なので必須。これで URL を知っているだけの外部からの書き込みを防げます）

### 4. 接続情報を `firebase-config.js` に貼る
プロジェクトの設定（歯車）→ 全般 → 「アプリを追加」→ ウェブ(`</>`) を登録すると `firebaseConfig` が表示されます。
`apiKey / authDomain / databaseURL / projectId / appId` を `firebase-config.js` にコピーします。
（`databaseURL` が出ない場合は Realtime Database 画面上部の URL を入れてください）

### 5. GitHub Pages で公開
1. GitHub で新規リポジトリを作り、4ファイルをルートに置いて push
2. **Settings → Pages → Branch: main / (root)** で公開
3. 公開された `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く
4. Firebase **Authentication → Settings → 承認済みドメイン** に `<ユーザー名>.github.io` を追加

## 使い方
- `?b=ボード名` でボードが分かれます。設定 → 「リンクをコピー」で共有できます。
- ペン / 消しゴム / 移動 / 囲って選択(V) / 四角・丸・矢印・直線 / 画像貼り付け（Ctrl+V・ドラッグ&ドロップ・ボタン）
- スタイルパネル：枠線の色・塗りつぶし有無と色・透明度・ペンと消しゴムの大きさ（選択中の図形にも適用）
- 2本指ピンチでズーム、ホイールでズーム、スペース+ドラッグまたは移動ツールで移動
- 設定の「指モード」：ONの間、指1本のドラッグが移動になる（ペン・マウスは描画）
- 保存：PNG / JPEG / JPNG(JPEG扱い) / ICO / PDF / HTML埋め込みコード（iframe）
- 設定：読み込む範囲、操作中の画質低下、解像度上限、ボードの広さ（無限 or サイズ指定・全員に反映）、UIカラー、背景色、ぼかし
- 画面が狭いときは「…」ボタンに残りの機能がまとまります

## 招集（通知）について
- サイトを開いた瞬間に通知の許可を求めます（ブラウザによっては最初のタップ時）。
- 招集ボタンを押すと、**ボードを開いている**（バックグラウンドのタブ含む）許可済みの人に通知が出ます。
- **サイトを完全に閉じている人**にも届けたい場合は、無料の [ntfy](https://ntfy.sh) を併用します。設定に表示されるトピック名（`aurora-board-<ボードID>`）を ntfy アプリで購読すると、招集時にプッシュが届きます。
  サーバーを持たずに「閉じている相手へのプッシュ」を実現できる、無料の現実的な方法がこれです。
- iPhone/iPad は「ホーム画面に追加」したウェブアプリでのみ通知が使えます（iOS の仕様）。

## 「無制限・無期限・無料」について（正直な注意）
- GitHub Pages は無期限・無料です。
- Firebase Spark は無料・期限なしですが **容量/転送量/同時接続に上限があります**（目安：保存 1GB、ダウンロード 月10GB、同時接続 100。数値は変わることがあるので Firebase の料金ページで確認してください）。
- 上限に当たりにくくする工夫を入れています：
  - 見えている範囲のタイルだけ読み込み（無限に描いても読み込み量は一定）
  - 線の自動間引き、画像は縮小して保存
  - 上限を超えると書き込みが止まるだけで課金はされません（Spark はカード登録なし）。
- 真の無制限は物理的にありえないため、「個人〜数十人規模なら実質困らない」安定性を狙った設計です。
- 画像は縮小して Firebase に保存するため、画像を多数貼ると容量を使います。

## 補足
- 「jpng」は JPEG（.jpg）として保存します。別形式の意図でしたらお知らせください。
- 消しゴムは線・図形を触れた単位で消します（部分消しではありません）。
